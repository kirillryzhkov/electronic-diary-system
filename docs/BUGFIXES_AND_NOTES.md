# Исправления и технические заметки

1. Добавлены подробные комментарии и docstring-и в основные файлы проекта.
2. Подготовлены отдельные файлы документации для защиты.
3. Уведомления доработаны для массового выставления оценок и создания домашнего задания.

## Что проверить после установки

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py test api.v1.tests
python manage.py runserver
```
