# Описание основных классов проекта

Этот файл дублирует техническое описание классов, чтобы их было проще объяснять на защите.

## 1. User

Файл: `users/models.py`

Кастомная модель пользователя, наследуется от AbstractUser.

Основные поля:

- role — роль пользователя;
- group — учебная группа для студента.

Свойство full_name возвращает фамилию и имя пользователя или username, если ФИО не заполнено.

## 2. Subject

Файл: `subjects/models.py`

Модель учебного предмета. Используется в назначениях преподавателей, оценках, расписании и домашних заданиях.

## 3. Grade

Файл: `grades/models.py`

Модель оценки.

Поля:

- student — студент;
- teacher — преподаватель;
- subject — предмет;
- value — оценка;
- comment — комментарий;
- grade_type — тип оценки;
- month — месяц аттестации;
- semester — полугодие;
- date — дата выставления.

Метод clean проверяет корректность оценки, месяца и полугодия.

## 4. StudyGroup

Файл: `academic/models.py`

Модель учебной группы. Хранит название группы, куратора и описание.

## 5. Classroom

Файл: `academic/models.py`

Модель кабинета. Хранит номер кабинета и описание.

## 6. TeachingAssignment

Файл: `academic/models.py`

Назначение преподавателя. Связывает преподавателя, предмет, группу и кабинет.

Эта модель важна, потому что через неё определяется, какие группы и предметы доступны преподавателю.

## 7. Schedule

Файл: `academic/models.py`

Модель расписания занятий. Хранит назначение, день недели, номер пары, время начала и окончания.

## 8. Attendance

Файл: `academic/models.py`

Модель посещаемости. Хранит студента, назначение, дату, статус и комментарий.

Статусы:

- present;
- absent;
- late;
- excused.

## 9. Homework

Файл: `academic/models.py`

Модель домашнего задания. Хранит назначение, тему, описание, дату создания и срок сдачи.

## 10. Notification

Файл: `notifications_app/models.py`

Модель уведомления. Используется для информирования студента о новой оценке или новом домашнем задании.

## 11. Основные View-классы

### GradesView

Показывает список оценок с учётом роли пользователя.

### GroupGradeEntryView

Позволяет преподавателю выставлять оценки сразу нескольким студентам выбранной группы.

### GradeJournalView

Показывает журнал оценок по дням с фильтрами.

### GradeSummaryExcelExportView

Формирует итоговую Excel-ведомость по группе и предмету.

### AttendanceListView

Показывает посещаемость с фильтрами.

### AttendanceExportExcelView

Формирует Excel-отчёт по посещаемости.

### NotificationListView

Показывает уведомления текущего пользователя.
