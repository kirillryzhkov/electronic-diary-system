# Краткий план демонстрации проекта на защите

## 1. Что сказать в начале

Мой дипломный проект называется Electronic Diary System. Это веб-приложение для автоматизации учебного процесса в образовательном учреждении. Система позволяет вести учёт групп, студентов, преподавателей, предметов, расписания, оценок, посещаемости, домашних заданий и уведомлений.

## 2. Что показать первым

1. Открыть главную страницу.
2. Войти под администратором.
3. Показать группы, предметы, кабинеты и назначения преподавателей.
4. Объяснить, что администратор управляет структурой учебного процесса.

## 3. Что показать под преподавателем

1. Войти под преподавателем.
2. Показать личный кабинет.
3. Открыть «Мои группы».
4. Показать выставление оценки одному студенту.
5. Показать массовое выставление оценок группе.
6. Открыть журнал оценок по дням.
7. Показать фильтры по группе, предмету, студенту и типу оценки.
8. Показать экспорт Excel.
9. Показать посещаемость и фильтры.
10. Показать домашние задания.

## 4. Что показать под студентом

1. Войти под студентом.
2. Показать только личные оценки.
3. Показать расписание.
4. Показать домашние задания.
5. Показать посещаемость.
6. Показать уведомления.

## 5. Что сказать про техническую часть

Проект разработан на Python с использованием Django. Для API используется Django REST Framework. Для авторизации API используется JWT. Для отчётов применяется openpyxl. Интерфейс создан на HTML, CSS и Django Templates. Данные хранятся в SQLite. Проект подготовлен к деплою на Render через Gunicorn и WhiteNoise.

## 6. Что сказать про безопасность

В системе реализовано разграничение доступа по ролям. Студент видит только свои данные. Преподаватель видит только свои группы и предметы. Администратор управляет справочниками. Формы защищены CSRF-токенами, API защищён авторизацией.

## 7. Что сказать в конце

В дальнейшем проект можно расширить: подключить PostgreSQL, добавить PDF-отчёты, email-уведомления, полноценный frontend на React или Vue, а также развернуть систему на сервере для постоянного использования.
