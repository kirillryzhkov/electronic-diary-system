# Функции проекта Electronic Diary System

Этот файл подготовлен для защиты дипломного проекта. В нём кратко и понятно продублированы основные функции системы, чтобы можно было быстро объяснить проект без просмотра исходного кода.

## 1. Назначение проекта

Electronic Diary System — это веб-приложение для автоматизации учебного процесса. Система помогает вести учёт студентов, преподавателей, групп, предметов, расписания, оценок, посещаемости, домашних заданий и уведомлений.

Проект решает следующие задачи:

- уменьшает ручное ведение учебной документации;
- ускоряет выставление и просмотр оценок;
- упрощает контроль посещаемости;
- помогает преподавателям выдавать домашние задания;
- предоставляет студентам доступ к личной учебной информации;
- формирует Excel-отчёты для анализа и ведомостей.

## 2. Роли пользователей

### Администратор

Администратор управляет структурой системы:

- создаёт и редактирует учебные группы;
- создаёт предметы;
- добавляет кабинеты;
- назначает преподавателей на группы и предметы;
- просматривает общие данные системы;
- имеет доступ к административным справочникам.

### Преподаватель

Преподаватель работает со своими группами и учебными данными:

- просматривает назначенные группы;
- выставляет оценки одному студенту;
- массово выставляет оценки всей группе;
- ведёт журнал оценок;
- отмечает посещаемость;
- добавляет домашние задания;
- экспортирует оценки и посещаемость в Excel;
- формирует итоговый отчёт по группе и предмету.

### Студент

Студент видит только свои данные:

- личные оценки;
- расписание своей группы;
- домашние задания;
- посещаемость;
- уведомления о новых оценках и заданиях.

## 3. Модуль оценок

Модуль оценок является одной из главных частей проекта. Он поддерживает несколько типов оценок:

- текущая оценка;
- месячная аттестация;
- полугодовая сессия;
- экзамен.

Для месячной аттестации указывается месяц, а для сессии и экзамена — полугодие. Это сделано специально под учебный процесс колледжа.

Основные возможности модуля:

- добавление оценки одному студенту;
- редактирование и удаление оценки;
- массовое выставление оценок группе;
- фильтрация по группе и предмету;
- журнал оценок по дням;
- фильтрация по типу оценки;
- расчёт среднего балла;
- экспорт оценок в Excel;
- итоговая ведомость по группе и предмету.

## 4. Модуль посещаемости

Модуль посещаемости предназначен для контроля присутствия студентов на занятиях.

Поддерживаемые статусы:

- присутствовал;
- отсутствовал;
- опоздал;
- уважительная причина.

Основные возможности:

- добавление записи посещаемости;
- редактирование записи;
- удаление записи;
- фильтрация по группе;
- фильтрация по предмету;
- фильтрация по статусу;
- экспорт посещаемости в Excel.

## 5. Модуль домашних заданий

Модуль домашних заданий позволяет преподавателю выдавать задания студентам конкретной группы по конкретному предмету.

В системе хранится:

- назначение преподавателя;
- тема задания;
- описание задания;
- дата создания;
- срок сдачи.

При создании нового домашнего задания студентам группы создаются уведомления.

## 6. Модуль уведомлений

Уведомления нужны для информирования студентов о важных изменениях.

Сейчас система поддерживает уведомления:

- о новой оценке;
- о новом домашнем задании.

Уведомления отображаются на отдельной странице. Пользователь может отметить одно уведомление как прочитанное или отметить все уведомления сразу.

## 7. Модуль отчётов

В проекте реализовано формирование Excel-отчётов через библиотеку openpyxl.

Доступные отчёты:

- экспорт всех доступных оценок;
- итоговая ведомость по группе и предмету;
- экспорт посещаемости.

Excel-файлы оформлены с заголовками, шириной колонок, фильтрами и цветовой подсветкой.

## 8. REST API и Swagger

Проект содержит API на Django REST Framework.

API используется для:

- получения списка предметов;
- создания предметов;
- получения оценок;
- создания оценки;
- просмотра, изменения и удаления оценки;
- получения среднего балла студента;
- получения статистики по предметам.

Swagger-документация доступна через drf-spectacular и помогает показать структуру API на защите.
